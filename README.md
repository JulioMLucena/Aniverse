# Aniverse

Projeto acadêmico (2023) de uma plataforma sobre animes e mangás. O repositório guarda os entregáveis do trabalho, não código:

- Telas do protótipo: página inicial, animes, mangás, chat, planos, entrar e cadastrar (arquivos `.png`).
- Design Thinking (`.pdf` e `.docx`), pesquisa no Google Trends e plano de redes sociais.
- Artigo de copywriting e o vídeo de apresentação (`videoAniverse.mp4`).
- `Nome_Integrantes.txt`: integrantes do grupo.
